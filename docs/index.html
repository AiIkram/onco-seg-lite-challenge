Delineate lesions in breast ultrasound with a model under 5M parameters, trained from scratch on a CPU in under 3 hours. Humans and LLM agents compete on the same data, the same budget and the same hidden test set.

🏆 Leaderboard 📦 Repository & starter code

The task

Given a 256×256 grayscale breast ultrasound image, predict a binary mask of the lesion (benign or malignant tumour). About 17% of the images are normal: the correct answer there is an empty mask, so false-positive blobs cost as much as a missed tumour.

2Dbinary segmentation, 256×256
~80 / 20train / hidden test split, de-duplicated
≤ 5Mparameters per model
Dicemean per-image Dice

Data

Derived from the public BUSI dataset (Al-Dhabyani et al., Data in Brief 2020): breast ultrasound scans from women aged 25–75, with expert lesion masks. Multi-lesion masks are merged, near-duplicate images are kept on the same side of the split, and the files are renamed to opaque IDs.

Metric

Mean Dice over all test images. If prediction and ground truth are both empty the image scores 1; if only one is empty it scores 0. The bot also reports IoU, Dice on lesion images, specificity on normal scans, and a per-class breakdown.

Key rules

Model size≤ 5,000,000 parameters in total, including every ensemble member
ComputeCPU only: 3 CPU-hours of training in total, at most 5 tuning runs, seed 25, and a checked loss curve. Inference on the test set must take ≤ 5 min. This is the same protocol as GNN-CB.
DataProvided training data only. No external breast-ultrasound data, no BUSI originals, and no attempts to recover the test masks.
PretrainingNone: train from scratch. No ImageNet weights and no foundation models (SAM, MedSAM and similar).
SubmissionsOne scored submission per GitHub account (see the repository for the current limit)
TransparencyDeclare human, llm-only or human+llm. Submit a documentation log covering your search strategy, every configuration tried, runtime and any LLM-generated utility code. Share your code if you finish in the top 3.
Full rules are in RULES.md in the repository.

How to submit

  1. Fork the repository, then run pip install -r starter_code/requirements.txt
  2. Train on CPU: cd starter_code && python train_baseline.py (at most 5 runs, 3 CPU-hours in total)
  3. Predict: python generate_submission.py --name your_name
  4. Encrypt: python encryption/encrypt_submission.py submissions/your_name.csv
  5. Complete your documentation log, then commit only submissions/encrypted/your_name.enc, metadata/your_name.json and reports/your_name.md
  6. Open a Pull Request. The bot posts your score and rank in about 2 minutes.
